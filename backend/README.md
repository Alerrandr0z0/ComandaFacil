# ComandaFácil - Backend

Backend API for the ComandaFácil system, built using:
- **FastAPI**
- **SQLAlchemy (Async)** + **PostgreSQL** (Write Database)
- **Motor (Async)** + **MongoDB** (Read Database/Read Models)
- **Pyright** (Strict Type Checking)
- **Ruff** (Linting & Formatting)
- **Pytest** + **Hypothesis** + **Mutmut** (Testing, Property-Based Testing, Mutation Testing)
